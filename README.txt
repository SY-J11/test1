국내 주식 랭킹 TOP 50 웹앱 - 업종 분류 개선판

파일 구성
- index.html: 화면 구조
- app.js: 6개 랭킹 탭 데이터 수집, 종목 분류 및 화면 처리
- style.css: PC/모바일 디자인
- cloudflare_worker.js: 네이버 증권 데이터 중계 Worker

이번 수정
- 종목코드 기반 업종 사전을 확장해 주요 상장사의 분류 정확도를 높였습니다.
- 코드 사전에 없는 종목은 기업명 키워드로 업종을 보완 분류합니다.
- '기타 / 사업 분야 확인 필요' 표기를 없애고, 실제 업종을 특정하기 어려운 경우에만 '업종 미확인 / 주요 사업 정보 확인 필요'로 표시합니다.
- 회사명 일부에 포함된 단어만으로 무리하게 테마를 붙이지 않도록 분류 규칙을 정리했습니다.
- 기존 6개 랭킹, 디자인, Worker 주소는 유지했습니다.

배포
1. 정적 호스팅(GitHub Pages 또는 Cloudflare Pages)에 index.html, app.js, style.css를 함께 업로드합니다.
2. cloudflare_worker.js는 Worker 코드를 수정하거나 재배포할 때 사용하는 파일입니다. 기존 Worker를 그대로 사용한다면 재배포할 필요가 없습니다.
3. Worker 주소는 https://st.mcraft-tiger-574.workers.dev/ 로 유지됩니다.

분류 데이터 안내
- 현재 버전은 별도 API 키 없이 작동하도록 종목코드 사전과 회사명 키워드 규칙을 사용합니다.
- 사전에 없는 신규 상장사나 사업구조가 복잡한 기업은 '업종 미확인'으로 남을 수 있습니다. 기업별 주요 사업을 완전 자동으로 확인하려면 OpenDART API 키와 서버 측 기업정보 연동이 추가로 필요합니다.
